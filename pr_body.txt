## Description
This PR implements the versioned inclusion signal engine as specified in #57. 
It introduces:
- `InclusionSignalVersion` model and migration for threshold configuration.
- `InclusionSignal` model to store the results and evidence summary.
- `InclusionReview` model for reviewers.
- `CalculateInclusionSignal` action that determines data sufficiency and candidate eligibility based on `CollaborationEvent`.
- Policies to enforce tenant-based restricted viewing (`InclusionSignalPolicy`, `InclusionReviewPolicy`).
- Synthetic offline evaluation datasets via Factories.
- Pest tests covering all calculation scenarios.

## Migration and Tenant Policy
- Migrations include `institution_id` for tenant boundary protection and cascading deletes.
- Policies restrict view access to `CampusAdmin` roles within the same institution to prevent data leakages and ensure signals remain restricted.
- Feature gated using Laravel Pennant `inclusion-signal-engine`.

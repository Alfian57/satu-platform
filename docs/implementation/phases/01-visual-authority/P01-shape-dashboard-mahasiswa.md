# P01: Shape dashboard mahasiswa

## Outcome

Mengunci job, hierarchy, content range, state, dan arah pengalaman dashboard.

## Prerequisites

Product, PRD, seed design, dan draft dashboard brief tersedia.

## Read Before Work

- [PRODUCT.md](../../../../PRODUCT.md)
- [PRD.md](../../../product/PRD.md)
- [DECISIONS.md](../../../governance/DECISIONS.md)
- [DESIGN.md](../../../../DESIGN.md)
- [UX strategy](../../../ux/UX_STRATEGY.md)
- [Screen inventory](../../../ux/SCREEN_INVENTORY.md)
- [Dashboard surface brief](../../../../.impeccable/surfaces/resources-js-pages-dashboard-tsx.md)
- Runtime context: `resources/js/pages/dashboard.tsx`, `resources/css/app.css`, app shell, navigation, and representative UI components.
- Phase-specific context: Impeccable `shape`/new-work guidance.

## Deliverables

Jalankan `$impeccable shape dashboard mahasiswa`; validasi dashboard brief;
eksplorasi dunia SATU tanpa referensi eksternal; hasilkan tiga visual compositions yang
benar-benar berbeda dan dapat dinilai.

## Out of Scope

Menulis runtime UI, memilih arah atas nama pengguna, atau menggunakan generic
metric-card dashboard.

## Verification

Setiap comp memperlihatkan realistic next action, recommendation reason,
deadline/review state, navigation, dan small-laptop viewport.

## Exit Criteria

Design brief dan tiga comp siap dibandingkan.

## Gate and Next Phase

- **Gate:** Human memilih atau meminta revisi; status menjadi `awaiting_approval`.
- **Next:** [P02: Record visual selection](P02-record-visual-selection.md)
